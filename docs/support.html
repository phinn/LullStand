Folded iPhone Duo · baby monitor · v1.0

What do I need? / 需要什么设备?

Two devices on the same Wi-Fi: one iPhone Duo set up as the Station (camera), any iPhone/iPad as the Parent (calendar view). No account, no cloud.

两台设备连同一 Wi-Fi:一台 iPhone Duo 立起当摄像机(Station),另一台 iPhone/iPad 当台历端(Parent)。无账号、无云。

Devices don't find each other / 搜不到设备

  • Both devices on same Wi-Fi (guest networks block discovery).
  • Allow local network permission when asked.
  • Restart both apps; the Station shows a 6-digit code, enter it on the Parent side.

Video freezes at night / 夜里画面卡

The stream auto-downgrades (60 fps → 15 fps → keyframe) on weak Wi-Fi; audio keeps flowing for 3 s before an offline alert. Move the router closer or use 5 GHz.

弱网自动降级(60fps→15fps→关键帧);断线 3 秒才告警,抖动不误报。建议靠近路由器或用 5 GHz 频段。

Covered-screen capsule / 合盖外屏胶囊

On iPhone Duo (iOS 27.1+), closing the cover keeps a live status capsule on the outer screen: CALM / CRY / OFFLINE. Open to return to full monitor.

iPhone Duo(iOS 27.1+)合盖后外屏亮状态胶囊:平静/哭闹/离线。翻开即回到全屏监护。
